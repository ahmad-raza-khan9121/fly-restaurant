# 🍽️ Fly Restaurant — Restaurant Website

<p align="center">

A modern, fully responsive restaurant website built from scratch using HTML5, CSS3, and vanilla JavaScript. It features an interactive digital menu, WhatsApp ordering, table reservations, shopping cart, wishlist, responsive layouts, and production-ready SEO, performance, and accessibility optimizations.

## ✨ Features

- 🍽️ Explore **76+ delicious menu items** across **9 food categories**
- 📋 Interactive digital menu with well-organized **Veg** and **Non-Veg** sections
- 🛒 Shopping cart and ❤️ wishlist with persistent state using `localStorage`
- 💬 WhatsApp-integrated online ordering for quick and seamless purchases
- 📅 Table reservation system with date, time, and guest selection
- 🍕 Detailed food pages with descriptions, pricing, ratings, and images
- 🔍 Live menu browsing with responsive category navigation
- 👤 Demo Login & Register modal interface
- 📱 Fully responsive layout optimized for mobile, tablet, laptop, and desktop devices
- 🚀 SEO optimized with Meta Tags, Open Graph Tags, JSON-LD, `sitemap.xml`, and `robots.txt`
- 📦 Progressive Web App (PWA) support via `manifest.json`
- ⚡ Performance optimized with lazy-loaded and compressed images
- ♿ Accessibility-friendly with semantic HTML5, keyboard navigation, ARIA labels, and visible focus states
- 🔒 Dedicated Privacy Policy page
- 🚧 Custom 404 Error page
- 🧩 Clean, modular, and well-organized project architecture
- 📄 Semantic HTML5 structure
- 📐 Mobile-first responsive design
- 🌍 Cross-browser compatibility
- 📁 Optimized asset organization for better maintainability and scalability

## 🚀 Installation

Follow these steps to run the project locally.

### 1️⃣. Clone the repository

```bash
git clone https://github.com/ahmad-raza-khan9121/fly-restaurant.git
```

### 2️⃣. Navigate to the project directory

```bash
cd fly-restaurant
```

### 3️⃣. Launch the project

Open the **index.html** file in your preferred web browser.

> **Note:** 💡 This project is built using pure HTML, CSS, and JavaScript. No package manager, build tools, or additional dependencies are required.
